# Task 2 generated artifacts

Run `task2.ipynb` from top to bottom to populate this directory. The notebook
creates the shared PACS split manifest, checkpoint metadata, comparison CSVs,
diagnostic feature caches, and figures required by the assignment.

Large `.pt` checkpoints, cached features, and generated figures are ignored by
Git. The stable source-only checkpoint path consumed by Task 3 is:

`checkpoints/source_only_seed6304.pt`
