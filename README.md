# Advanced Topics in Machine Learning Assignment 1

## Requirements

From the repository root, create a virtual environment and install the dependencies:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Run tasks

From the repository root:

```bash
(cd task1 && ../.venv/bin/python task1.py)
(cd task2 && ../.venv/bin/python task2.py)
(cd task3 && ../.venv/bin/python task3.py)
(cd task4 && ../.venv/bin/python task4.py)
```
